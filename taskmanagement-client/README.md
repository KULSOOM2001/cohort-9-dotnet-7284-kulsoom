# Task Management System — Frontend

React frontend for the Task Management System, built with Vite.

## Setup

1. Install dependencies: `npm install`
2. Create a `.env` file with `VITE_API_BASE_URL=https://localhost:7277/api`
3. Run the dev server: `npm run dev`

## Features

- User authentication (login/register)
- Task CRUD with role-based access
- Dashboard with task status counts
